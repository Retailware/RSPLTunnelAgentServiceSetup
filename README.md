# RSPLTunnelAgentServiceSetup

Service-only update setups for the RSPL tunnel agent's automatic update (`RSPLTunnelServiceUpdate_<version>.exe`).
Agents download the version the update server names; these setups are not for installing a new PC.

**Full setup (new or existing PC):** [RSPLMainInstallerSetup](https://github.com/Retailware/RSPLMainInstallerSetup)

Latest full setup: https://github.com/Retailware/RSPLMainInstallerSetup/releases/latest/download/RSPLTunnelServiceSetup.exe

`version.json` is read by trays of agent 1.15.0 and older; keep it here.
